# Testes comunitários

No momento, ainda não há patch instalável no GitHub. O pacote de teste local contém recursos do jogo e não deve ser enviado como anexo público. Estamos trabalhando em um patch que aplique as mudanças somente à cópia local do jogador.

Quando o patch estiver disponível:

1. Faça uma cópia de segurança dos arquivos indicados pelo instalador.
2. Use uma cópia legítima do jogo e siga as instruções da versão específica do patch.
3. Teste primeiro no clone ou numa pasta separada, nunca na instalação principal.
4. Registre versão do jogo, capítulo/tela, passos para reproduzir e resultado observado.
5. Envie o relato pelas Issues ou pelo Discord.

Não envie arquivos do jogo, saves, executáveis ou vídeos extraídos nas Issues. Para erros de tradução, informe o texto em inglês, a tradução mostrada, o contexto e uma captura de tela quando possível.
